# CornerMan Box 🥊

**CornerMan Box** es una aplicación Android diseñada para optimizar el entrenamiento de boxeo de forma autónoma. El proyecto busca centralizar la gestión de tiempos, la formación técnica y la motivación del atleta en una única herramienta "manos libres".

Este proyecto se desarrolla como **Proyecto Intermodular** para el Grado Superior en Desarrollo de Aplicaciones Multiplataforma (DAM).

## 🚀 Estado del Proyecto: Fase 1 Finalizada
Actualmente, el repositorio refleja la culminación de la **Fase de Cimentación y Diseño Estructural (25/03 - 19/04)**.

### Implementaciones actuales:
* **Arquitectura robusta**: Estructura de paquetes siguiendo el patrón **MVVM** (Model-View-ViewModel) en Java.
* **Diseño de Interfaz (UI/UX)**: Layouts de alto contraste optimizados para gimnasios, utilizando **Material Design 3**.
* **Navegación**: Implementación de *Jetpack Navigation Component* con menú inferior funcional.
* **Persistencia Base**: Configuración inicial de la base de datos local con **Room**.
* **Compatibilidad**: Optimizada para dispositivos desde **Android 7.0 (API 24)**.
